# ZEPTO SQL Data Analysis Project

## Overview

This project focuses on analyzing the product and inventory dataset of the popular e-commerce company ZEPTO using SQL Server. The project includes data loading, exploratory data analysis (EDA), data cleaning, data transformation, and business analysis using SQL queries.

The main objective of this project is to identify meaningful business insights related to product pricing, discounts, inventory availability, category-wise revenue, and product performance through structured SQL analysis.

---

## Dataset

The dataset contains product and inventory information from ZEPTO including:

* Product Name
* Category
* MRP
* Discount Percentage
* Discounted Selling Price
* Available Quantity
* Product Weight
* Stock Availability

---

## Tools Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)

---

## Project Steps

### 1. Data Loading

* Imported the dataset into SQL Server database
* Created a table for storing product and inventory data
* Verified successful data loading

### 2. Exploratory Data Analysis (EDA)

Performed initial exploration using SQL queries:

* Viewed complete dataset
* Checked column names and data types
* Counted total number of records
* Displayed sample records
* Identified unique product categories
* Analyzed stock availability

### 3. Data Cleaning

Performed data cleaning and validation steps:

* Checked for NULL values
* Identified invalid pricing records
* Removed records with incorrect price values
* Verified record count after cleaning

### 4. Data Transformation

Performed data manipulation and transformation:

* Converted product prices from paise to rupees
* Updated column data types for better readability
* Modified data types to avoid overflow issues during calculations

### 5. SQL Business Analysis

Executed SQL queries to answer important business questions such as:

* Top discounted products
* Out-of-stock high-value products
* Category-wise revenue analysis
* Premium products with low discounts
* Categories with highest average discounts
* Price-per-gram analysis
* Product weight classification
* Inventory weight analysis

### 6. Reporting

* Documented all SQL queries with explanations
* Captured query outputs and business insights
* Prepared a structured project report for GitHub and portfolio presentation
